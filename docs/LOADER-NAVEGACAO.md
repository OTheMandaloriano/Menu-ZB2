# Biblioteca e navegação do cliente 1.16

O cliente usa uma janela nativa com navegação lateral sempre disponível.

- Biblioteca: cartão de Zumbi Blocks 2. Selecionar abre a tela desse produto, não inicia o jogo.
- Meu acesso: ID local, validade e acesso à ativação.
- Ajuda: primeiro uso e opção de reduzir movimento na sessão atual.
- Créditos e detalhes: acessíveis pelas páginas correspondentes, sempre com Voltar.

Somente Zumbi Blocks 2 está disponível. A navegação permite ampliar o catálogo no
futuro, mas nenhuma integração com outro jogo foi criada nesta entrega.

Para ativar: Biblioteca > Selecionar > Abrir arquivo ou colar a licença > Ativar acesso.
Para carregar: abrir o jogo, entrar na partida e aguardar AUTO-INJECT, ou usar
Carregar menu quando a leitura da partida estiver confirmada. INSERT abre o menu no jogo.

A capa é uma ilustração original gerada para a biblioteca. Não é arte oficial nem
captura do jogo. Está incorporada ao executável; não exige conexão ou arquivo externo.
As transições são curtas, interrompíveis e não bloqueiam os controles. O indicador
de progresso acompanha o estado ocupado, sem porcentagem fictícia.

Não há login social, loja online, promessa de indetectabilidade ou botão que desativa
o antivírus. As referências visuais foram usadas para organização e hierarquia.
