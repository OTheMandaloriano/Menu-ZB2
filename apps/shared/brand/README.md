# Ícones ZB2

Arte original gerada com o image_gen integrado, em três chamadas. Os PNGs são os
originais preservados; ICOs apenas codificam tamanhos Windows 16/20/24/32/40/48/64/128/256.
Nenhuma dependência de download em runtime.

- admin: Z marfim angular, base grafite, azul #2563eb, escudo/fechadura.
- client: mesma família, ciano #0891b2, seta de iniciar.
- menu: mesma família, verde #10b981, controles deslizantes.

Prompt-base: “Windows desktop application icon for original brand ZB2; transparent
background around charcoal rounded-square tile, ivory angular Z monogram, restrained
beveled enamel, orthographic view, readable at small sizes, no extra words or objects.”
Admin acrescentou escudo/fechadura azul; Cliente e Menu utilizaram o PNG do Admin
como referência para preservar composição, proporções e materiais, substituindo
somente a cor e o símbolo funcional descritos acima. Proveniência/hash em provenance.json.

Admin ICO é o recurso PE 1 do ZB2Admin. Cliente ICO é o recurso PE 1 do ZB2Menu;
Menu ICO é o recurso PE 2 e também é entregue como ativo independente. Não foi
alterada a DLL do jogo apenas para adicionar uma marca.
